# Project source and download safety

The canonical project is [pseudo-r/Public-ESPN-API](https://github.com/pseudo-r/Public-ESPN-API). Its documentation and Python services are distributed as source in this repository. This project does not provide API-key installers, a desktop application, or Windows/macOS/Linux application installers. The public ESPN endpoints documented here do not require downloading an API key.

Treat similarly named sites and their download links as third-party content, including espnapi.com, reported in [issue #19](https://github.com/pseudo-r/Public-ESPN-API/issues/19). A matching name, copied README, or a GitHub download link does not establish affiliation. Verify the repository owner and full destination URL before using source or instructions. Do not run terminal commands from an unverified download page.

For setup, start with the README and service instructions in the canonical repository. To report misleading branding or downloads, open an issue here with the page URL and a description of the claim. Do not upload executables, credentials, tokens, or personal information.

Website hosting providers and domain operators control removal of external content. Closing a repository issue does not establish that an external site has been removed or its downloads verified.
